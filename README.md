# Personal Finance Tracker

A simple Java-based personal finance tracker to manage and keep track of your income, expenses, and financial transactions.

## Features
- **Add Transaction**: Allows users to add an income or expense transaction with details such as type, category, amount, and date.
- **View All Transactions**: View a list of all the transactions entered into the system.
- **Data Persistence**: Save and load transaction data to and from a file, ensuring data is retained across sessions.
- **Balance Calculation**: Calculates and shows the remaining balance based on the total income and expenses.
- **Remainder for Due Payments**: Keeps track of EMIs or other recurring payments and reminds the user of upcoming due dates.

## Technologies Used
- **Java**: Core programming language for the backend.
- **File Handling**: Used to save and load transaction data.
- **Scanner**: For taking user input via the command line.

## How to Run the Project
1. Clone or download the repository.
2. Open the project folder in your Java IDE or VS Code.
3. Compile and run the `FinanceTracker.java` file.
4. Follow the on-screen instructions to add transactions and view them.

### Usage
When you run the program, you'll be presented with the following options:
1. **Add Transaction**: Add a new income or expense.
2. **View All**: View all recorded transactions.
3. **Balance View**: View your current balance, including your income and expenses.
4. **Save & Exit**: Save the current data and exit the application.

You can input details such as the type (Income/Expense), category, amount, and the transaction date.

### Additional Features:
- The app will calculate and display the balance automatically as you add new transactions.
- You can also add a **remainder** for your due payments (e.g., EMIs). The program will remind you of upcoming due dates to help manage your finances better.
